
# Sistema Solar

## Descripción
Aplicación web informativa que permite explorar los ocho planetas que forman parte de nuestro Sistema Solar. Presenta información básica de cada planeta mediante una interfaz sencilla

## Objetivo
Desarrollar, organizar, versionar y desplegar una aplicación web utilizando tecnologías fundamentales del desarrollo web y un servidor Apache.

## Tecnologías utilizadas
- HTML5: estructura de la página.
- CSS3: diseño y estilos visuales.
- JavaScript: interactividad.
- Apache: servidor web.
- XAMPP: entorno de servidor local.
- Git y GitHub: control de versiones

## Estructura del proyecto

```text
reto 2 despliegue web/

index.html
styles.css
script.js
README.md

images/ earth.webp
```

## Contenido de la aplicación
- Página de inicio.
- Presentación de los ocho planetas.
- Sección informativa sobre el Sistema Solar.
- Dato curioso interactivo mediante JavaScript.

## Preparación y optimización
- Organización de archivos y directorios.
- Optimización de imágenes.
- Minificación de archivos CSS y JavaScript.
- Empaquetado de la aplicación en formato ZIP.

## Control de versiones
El proyecto utiliza Git para el control de versiones y GitHub como repositorio remoto.

## Configuración del servidor
- Servidor web: Apache.
- Entorno: XAMPP.
- Sistema operativo: Windows.
- Puerto: 80.
- Ruta local: http://localhost/tuapp

## Despliegue
La aplicación se ejecuta localmente mediante Apache, utilizando una configuración Alias para acceder al proyecto desde el navegador
